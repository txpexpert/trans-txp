Documents requis par code SH

Saisissez un code SH (2 à 10 chiffres) pour voir les formalités propres au produit : contrôles sanitaires, conformité industrielle, licences, agréments, fiscalité intérieure. Chaque pièce indique l'organisme compétent, son statut et sa source.

Les deux premiers chiffres donnent le chapitre ; au-delà, les positions qui font l'objet d'une mesure spécifique (licence, antidumping…) sont signalées.
IXP-Import-eXPert · Usage informatif. Les listes officielles évoluent (MIC, ONSSA, ANRT) : vérifier le code NC10 exact sur le portail de la douane et auprès de l'organisme avant l'importation.
