Lecture pour l’importateur

Trois conséquences pour vos achats.

Le coût de l’énergie remonte

+37 % sur neuf mois. Le fret et les produits à forte intensité énergétique suivent : révisez vos hypothèses de coût de revient pour 2027.

L’Asie gagne des parts

Un fournisseur asiatique ne donne en général droit à aucune préférence. Comparez le prix rendu, droits compris, à une offre européenne ou turque avec EUR.1.

Les produits finis sous surveillance

Le déficit sur les produits finis se creuse. Les hausses ciblées de droits et les mesures de défense commerciale visent d’abord ces produits.
